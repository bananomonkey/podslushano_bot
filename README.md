# Подслушано в Колледже — Telegram-бот

Бот на **aiogram 3.x** для приёма анонимных постов от подписчиков с модерацией
и публикацией в привязанный Telegram-канал. Также поддерживает прямую связь
с администрацией.

## Возможности

- 📝 «Предложить пост» — пользователь отправляет текст/фото/видео, пост уходит
  админу на модерацию с кнопками «Опубликовать» / «Отклонить».
- ✅ При публикации пост уходит в канал анонимно с подписью `#подслушано`.
- 💬 «Связь с админом» — прямой диалог пользователь ↔ админ через бота
  (админ видит имя, username и ID пользователя, отвечает через Reply).
- 🛠 Команда `/admin` — админ-панель. Виден только администраторам.
- 👥 Главный админ может добавлять и удалять **суб-админов**, которые тоже
  могут фильтровать (публиковать / отклонять) посты.
- 💾 Хранение очереди постов, диалогов и списка админов в SQLite (`aiosqlite`).

## Админ-панель

Команда `/admin` доступна только администраторам. Для обычных пользователей она
не отображается в меню команд (используется `setMyCommands` со scope на чат
админа) и на попытку ввода бот не отвечает.

- 👑 **Главный администратор** — пользователь с ID из переменной окружения
  `ADMIN_ID`. Имеет полный доступ: добавление/удаление суб-админов, список
  админов.
- 👤 **Суб-админ** — добавляется главным админом через
  `/admin → ➕ Добавить админа`. Достаточно переслать бота любое сообщение от
  нужного пользователя или отправить его числовой ID. Суб-админ получает
  доступ к `/admin` и может публиковать / отклонять посты.

Новые посты и сообщения «Связь с админом» рассылаются **всем** админам, поэтому
модерировать может любой из них. Как только один админ обработал пост, у
остальных кнопки перестают работать («Пост уже обработан»).

## Развёртывание на GitHub → Bothost.ru

### 1. Залейте проект на GitHub

```bash
cd podslushano_bot
git init
git add .
git commit -m "Initial commit"
git branch -M main
git remote add origin https://github.com/ВАШ_ЛОГИН/ВАШ_РЕПОЗИТОРИЙ.git
git push -u origin main
```

(Либо просто загрузите файлы через веб-интерфейс GitHub: **Add file → Upload files**.)

### 2. Подключите репозиторий в Bothost

1. Зайдите в панель [Bothost.ru](https://bothost.ru) → **Создать проект**.
2. Выберите способ **«Импорт из GitHub»** (или загрузите архив `.zip`, если
   импорт из GitHub недоступен на вашем тарифе).
3. Укажите:
   - Язык: **Python**
   - Файл запуска: **main.py**
   - Файл зависимостей: **requirements.txt** (Bothost выполнит `pip install -r requirements.txt` автоматически)

### 3. Переменные окружения (Environment Variables)

В настройках проекта на Bothost добавьте:

| Переменная    | Значение                                                              |
|---------------|------------------------------------------------------------------------|
| `BOT_TOKEN`   | Токен бота от [@BotFather](https://t.me/BotFather)                    |
| `ADMIN_ID`    | Ваш числовой Telegram ID (узнать у [@userinfobot](https://t.me/userinfobot)) |
| `CHANNEL_ID`  | ID канала (`-1001234567890`) или его `@username`, если канал публичный |

### 4. Права бота в канале

1. Добавьте бота в канал как **администратора**.
2. Обязательно выдайте право **«Публикация сообщений» (Post Messages)**.
3. Остальные права не обязательны.

### 5. Запуск

После настройки переменных нажмите **«Запустить»** в панели Bothost.
При старте бот сам создаст файл базы данных `bot_database.db` и проверит
доступ к каналу (в логах появится подтверждение или предупреждение).

## Как получить `CHANNEL_ID`

- Если канал **публичный** — просто используйте `@username_канала` в переменной `CHANNEL_ID`.
- Если канал **приватный** — перешлите любое сообщение из канала боту
  [@getidsbot](https://t.me/getidsbot) или [@userinfobot](https://t.me/userinfobot),
  чтобы получить числовой ID вида `-100xxxxxxxxxx`.

## Локальный запуск (для теста)

```bash
python -m venv venv
source venv/bin/activate   # Windows: venv\Scripts\activate
pip install -r requirements.txt

export BOT_TOKEN=xxx
export ADMIN_ID=123456789
export CHANNEL_ID=-1001234567890

python main.py
```
